# Protein Sequence Similarity Analysis

## Overview
This project performs exploratory analysis to understand similarity patterns among protein sequences using numerical representations and Python-based data analysis techniques.

## Objectives
- Analyze basic characteristics of protein sequences
- Compute similarity between protein entries using cosine similarity
- Visualize similarity patterns using a heatmap

## Dataset
The dataset consists of a small, synthetic set of protein sequences with associated attributes such as sequence length and family classification.  
This dataset was created for analytical demonstration purposes.

## Methodology
- Protein sequence attributes were loaded and preprocessed using Pandas
- Numerical features were standardized using StandardScaler
- Cosine similarity was computed to measure similarity between protein entries
- Results were visualized using a similarity heatmap

## Project Structure
- `data/` – Sample protein sequence dataset
- `python/` – Python scripts used for analysis
- `visuals/` – Output visualizations generated from the analysis

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Key Insights
- Protein entries with similar sequence characteristics show higher similarity
- Simple numerical attributes can be used for exploratory protein analysis

## Disclaimer
The dataset used in this project is synthetic and intended solely for learning and demonstration purposes.
